# Codex CLI 요청 프롬프트 — 1단계 시각화 학습자료 제작

아래 내용을 그대로 복사해서 `tumblbug-study` 폴더에서 `codex` 실행 후 첫 메시지로
붙여넣으세요.

---

```
docs/01-linktree-clone/PLAN.md 을 먼저 읽고, 그 내용을 바탕으로
docs/01-linktree-clone/tutorial/ 폴더에 초심자가 "처음부터 끝까지 그대로
따라 하면 Linktree 클론을 완성"할 수 있는 시각화된 학습자료를 만들어줘.

[대상 독자]
- UI/UX, 프로덕트, 개발, 컴퓨터공학 지식이 전혀 없는 완전 초심자
- 설명 없이 코드만 던지면 못 따라감. 왜 이렇게 하는지 매번 짧게 설명 필요

[형식]
- 브라우저에서 더블클릭으로 바로 열리는 순수 HTML/CSS/JS 파일 (빌드 도구 없이 동작)
- index.html 하나로 시작하되, 내용이 너무 길어지면 week1.html ~ week4.html 로
  나누고 index.html에서 이동할 수 있게 링크로 연결
- 외부 라이브러리 최소화 (오프라인에서도 열리도록), 폰트는 시스템 폰트 사용
- 라이트/다크 모드 모두 고려한 색상 설계

[시각화 요소 — 반드시 포함]
1. 전체 진행률 표시 (체크리스트 완료 개수를 상단에 프로그레스 바로)
2. 체크박스로 된 할 일 목록 — 체크 상태는 브라우저에 저장되어 새로고침해도 유지
3. 개념 설명용 다이어그램 (SVG로 직접 그릴 것, 이미지 파일 사용 금지):
   - 클라이언트-서버-데이터베이스 흐름도 (전체 구조 이해용)
   - User-Link 테이블 관계도 (ERD)
   - 회원가입/로그인 흐름도
4. 코드 블록은 복사 버튼이 있고, 줄바꿈/들여쓰기가 유지되도록 monospace 스타일로
5. 주차별(1~4주차) 탭 또는 아코디언으로 섹션 구분, 지금 어느 주차인지 한눈에 보이게

[콘텐츠 구성 — PLAN.md의 주차별 체크리스트를 그대로 따를 것]
- 시작하기 전: Node.js/Git/VSCode/Supabase/Vercel 계정 준비 체크리스트
- 1주차: 기획 (와이어프레임 그리는 법, 기능 목록 정리하는 법 — 글쓰기 위주, 코드 없음)
- 2주차: Next.js 프로젝트 생성 → Supabase 프로젝트/테이블 생성 → 회원가입/로그인 구현
  (명령어와 실제 동작하는 코드를 단계별로, 각 단계 끝에 "여기까지 됐는지 확인하는 법" 포함)
- 3주차: 링크 추가/수정/삭제(CRUD) 구현 → 공개 페이지 구현
- 4주차: Vercel 배포 → 실제 사용 테스트 → 완료 기준 체크

[진행 방식]
- 한 번에 다 만들지 말고, 먼저 전체 구조(페이지 구성, 다이어그램 목록, 각 주차에
  들어갈 내용 개요)를 간단히 제시하고 나한테 확인받은 다음 실제 콘텐츠를 채워줘
- index.html(또는 전체 구조) 완성 후, 2주차 코드 파트는 실제로 Next.js+Supabase로
  동작하는 코드인지 한 번 더 검토해줘

기술 스택 참고는 README.md, 전체 로드맵은 ROADMAP.md 참고.
```

```
사람 기준으로 한 단계 더 쪼개서 다시 설명해줘.
```

**다음 단계로 넘어갈 때**
```

같은 형식으로 2단계 학습자료를 docs/02-buy-me-a-coffee-clone/tutorial/에
만들어줘. 1단계 tutorial/index.html의 디자인/구조를 그대로 재사용하고
콘텐츠만 2단계에 맞게 바꿔줘.
```

```

설명 없이 등장하는 용어나 갑자기 건너뛰는 단계가 있는지 점검해줘.
```
