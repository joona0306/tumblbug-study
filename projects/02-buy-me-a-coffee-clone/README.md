# 02-buy-me-a-coffee-clone — 2단계 정답 코드

`docs/02-buy-me-a-coffee-clone/tutorial/` 교재를 따라 만든 **검증된 정답 코드**입니다.
1단계(`01-linktree-clone`)의 마지막 코드를 복사해서 시작했습니다.

## 체크포인트
```bash
git tag -l "coffee-*"
```

## 실행하는 법
```bash
npm install
# .env.local 을 교재 안내대로 채운 뒤 (DB 주소, 인증 비밀키, 토스페이먼츠 테스트 키)
npm run db:migrate
npm run dev
```
