# 운영·개선 예시 사례 (17~20주차) — ⚠️ 가상 사례

> 실제 사용자와의 운영(17~20주차)은 **교재를 마친 학습자가 강의 뒤에 직접** 한다.
> 이 폴더는 그 과정을 미리 보여 주는 **예시 답안**이다. 방문자·후원·설문 응답은 모두 **가상**으로 만든 것이다.
> (코드 개선·측정값처럼 실제로 한 것은 "실제" 라고 따로 표시한다)

## 가상 사례 한눈에

| 항목 | 내용 |
|---|---|
| 프로젝트 | [가상 사례] 손으로 빚은 달항아리 미니 화병 — 창작자 "달빛공방 (가상)" |
| 기간 | 2주 |
| 방문자 | 42명 (상세 보기 기준) |
| 리워드 | 미니 화병 1개 25,000원(한정 30) · 2개 세트 45,000원(한정 10) · 응원 엽서 5,000원(배송 없음) |
| 결과 | 후원 14건 시도 → 결제 완료 11건 · 모인 금액 285,000원 (목표 50만 원의 57%) |

## 직접 만들어 보기

개발 DB(이름이 `_dev` 로 끝나는 DB)에서:
```
npm run ops:simulate                     # 가상 사례 데이터를 만든다 (여러 번 해도 같은 결과)
npm run ops:check -- --project=번호      # 마지막 줄에 나온 프로젝트 번호로 — 18주차 분석의 출발점
```
- 운영 DB 에서는 실행되지 않는다 (DB 이름 검사). 가상 계정(`@sim.moa.test`)은 비밀번호가 없어 로그인할 수 없다
- 예시 계정(`moa_admin@seed.moa.test`)으로 로그인하면 관리자 화면에서 이 프로젝트의 후원·결제 실패를 볼 수 있다
