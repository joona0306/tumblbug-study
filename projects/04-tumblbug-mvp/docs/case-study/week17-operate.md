# 17주차 — 2주 운영하며 쌓인 것 (⚠️ 가상 사례)

> 학습자는 이 주에 `docs/launch.md` 대로 실제 창작자 1명·지인 3~5명과 운영을 시작한다.
> 아래는 그 결과가 어떤 모양으로 쌓이는지 보여 주는 **가상** 기록이다. `npm run ops:simulate` 로 같은 데이터를 만들 수 있다.

## 1. 퍼널 (`npm run ops:check -- --project=번호`)

```
■ 퍼널 (방문자·프로젝트 기준 · 프로젝트 N만)
     42  상세 보기
     24  후원 시작 (리워드)   (앞 단계의 57.1% · 상세의 57.1%)
     20  배송지   (앞 단계의 83.3% · 상세의 47.6%)
     14  결제 요청   (앞 단계의 70% · 상세의 33.3%)
     11  결제 완료   (앞 단계의 78.6% · 상세의 26.2%)
```
- **핵심 지표**(상세를 본 사람 중 결제 완료): **26.2%**
- 언뜻 보면 가장 많이 빠지는 곳은 "상세 → 리워드"(57.1%) 다. **정말 그럴까?** → 18주차에 다시 본다
