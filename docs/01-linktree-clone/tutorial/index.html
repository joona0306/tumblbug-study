  • 할 일마다 체크박스가 있습니다. 체크하면 이 브라우저에 저장되어 새로고침해도 유지되고, 맨 위 진행률 바가 채워집니다.
  • 상단 탭에서 지금 할 차례인 주차는 파란 테두리로 표시됩니다.
  • 코드 블록 오른쪽 위의 복사 버튼을 누르면 코드가 그대로 복사됩니다. 코드 위의 회색 줄은 그 코드를 넣을 파일 경로입니다.

막혔을 때 비교할 "정답 코드"

이 교재의 모든 코드는 작성자가 실제로 실행해서 동작을 확인한 코드입니다. 각 단계가 끝난 시점의 전체 코드를 GitHub에 체크포인트로 남겨 두었습니다. 단계마다 있는 "정답 코드 보기" 링크를 누르면 그 시점의 코드 전체를 볼 수 있어요. 내 코드와 한 줄씩 비교하면 대부분의 문제를 찾을 수 있습니다.

큰 그림: 우리가 만들 서비스는 어떻게 움직이나

코드를 쓰기 전에, 완성된 서비스 안에서 데이터가 어떻게 오가는지 먼저 봅시다. 앞으로 나오는 모든 코드는 이 그림의 어느 한 칸에 들어갑니다.

📖 용어 풀이
  • 클라이언트(Client): 서비스를 "사용하는 쪽". 여기서는 사용자의 웹 브라우저(크롬 등)입니다.
  • 서버(Server): 요청을 받아 일을 처리하고 결과를 돌려주는 "일하는 쪽" 컴퓨터입니다. 우리가 짠 Next.js 코드가 여기서 실행됩니다.
  • 데이터베이스(DB): 회원 정보, 링크 같은 데이터를 표(테이블) 형태로 오래 보관하는 창고입니다. 우리는 Neon이라는 서비스가 빌려주는 Postgres DB를 씁니다.
  • API: 프로그램끼리 "이렇게 요청하면 이렇게 답해줄게"라고 정해둔 약속(창구)입니다. 예: /api/health로 요청하면 서버가 DB 상태를 알려줌.
  • ORM(Drizzle): 자바스크립트 코드를 DB가 알아듣는 언어(SQL)로 바꿔주는 번역기입니다.
💡 왜 이 도구들을 쓰나요?

Next.js 하나로 화면과 서버 코드를 모두 자바스크립트로 쓸 수 있어 배울 언어가 하나뿐입니다. DB는 Neon, 로그인은 Better Auth를 쓰는데, 둘 다 "우리 DB 안에 무엇이 저장되는지"를 눈으로 볼 수 있어서 로그인이 실제로 어떻게 동작하는지 이해하기 좋습니다.

시작하기 전: 준비물 체크리스트

이 교재는 0단계(기초)를 마쳤다고 가정합니다. 터미널 명령어 실행, HTML/CSS/JS 기초, Git 커밋이 아직 낯설다면 0단계부터 보고 오세요. 아래 준비물은 0단계에서 이미 했다면 확인만 하고 체크하면 됩니다.

1개발 도구 설치 확인

VSCode를 열고 Ctrl + `(백틱, 숫자 1 왼쪽 키)로 터미널을 연 다음, 오른쪽 위 ∨ 버튼에서 Git Bash를 선택하세요. 이 교재의 모든 명령어는 Git Bash 기준입니다.

✅ 확인하는 법
  • node -v 결과가 v20.9.0 이상이어야 합니다. (작성자 검증 환경: v22.14.0) 낮다면 nodejs.org에서 LTS 버전을 설치하세요.
  • npm -v, git --version 모두 숫자(버전)가 나오면 됩니다.

Git에 내 이름과 이메일을 한 번 등록해 둡니다. 코드를 저장(커밋)할 때 "누가 저장했는지" 기록하는 용도예요.

🆘 막혔을 때
node: command not found가 나와요

Node.js를 설치한 뒤 VSCode를 완전히 껐다가 다시 켜야 새 명령어를 인식합니다.

터미널 목록에 Git Bash가 없어요

git-scm.com에서 Git을 설치하면 Git Bash가 함께 설치됩니다. 설치 후 VSCode를 다시 켜세요.

3작업 폴더 정하기

이번 과정의 코드를 담을 폴더를 하나 정합니다. 예시에서는 문서 폴더 아래 dev라는 폴더를 씁니다. 경로에 한글이나 띄어쓰기가 없는 곳을 추천합니다.

✅ 확인하는 법pwd(지금 위치 출력) 결과가 /c/Users/내이름/dev처럼 나오면 됩니다. 2주차 첫 명령어는 이 폴더에서 실행합니다.

이 단계를 끝냈다는 기준

4주차 마지막에 아래를 모두 만족하면 1단계 완료입니다. (체크는 4주차 페이지에서 합니다)

  • 실제 URL로 배포되어 다른 사람의 휴대폰에서도 접속된다
  • 회원가입 → 로그인 → 링크 3개 등록 → 공개 페이지에 정상 표시
  • 4번째 링크 추가가 화면뿐 아니라 서버에서도 막힌다
  • 다른 사람의 링크는 수정·삭제할 수 없다
  • 지인 1명이 실제로 자기 SNS 프로필에 이 링크를 써본다
