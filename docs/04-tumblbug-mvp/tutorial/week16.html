① 내 Windows 버전 확인

Win + R → winver → Enter. 창에 나온 버전과 OS 빌드를 봅니다.

Windows 1123H2 (빌드 22631) 이상

② 가상화가 켜져 있는지

작업 관리자(Ctrl+Shift+Esc) → 성능 → CPU → 오른쪽 아래 가상화: 사용. "사용 안 함"이면 컴퓨터를 켤 때 BIOS(보통 F2·Del)에서 Intel VT-x / AMD SVM 을 켭니다 (메뉴 위치는 제조사마다 달라요 — "제조사 이름 + 가상화 켜기"로 검색).

③ Windows 기능 두 개 켜기 (관리자 권한 + 재부팅)

  1. 시작 → "Windows 기능 켜기/끄기" 검색 (Windows 10 에서 안 나오면: 제어판 → 프로그램 → Windows 기능 켜기/끄기)
  2. ☑ 가상 머신 플랫폼 · ☑ Linux용 Windows 하위 시스템 — 둘 다
  3. 확인 → 재부팅

--no-distribution = Ubuntu 같은 리눅스는 설치하지 않고 WSL 만. Docker Desktop 이 자기 리눅스를 만듭니다.

🔁 방금 무슨 일이 일어났나Windows 안에 작은 리눅스(WSL 2)를 켜고, 그 위에 Docker 를 올렸습니다. 이제 이 컴퓨터에서 리눅스용 이미지를 만들고 돌릴 수 있습니다 — EC2(리눅스)와 같은 환경이에요.
🤔 스스로 확인
가상 머신 플랫폼을 끄면 Docker Desktop 은 왜 켜지지 않을까?

Docker Desktop 은 WSL 2 위에서 돌고, WSL 2 는 리눅스를 가상 머신으로 돌리는데, 가상 머신을 Windows 가 쓰게 해 주는 부품이 바로 가상 머신 플랫폼이기 때문입니다 (사슬의 두 번째 고리).

2앱을 이미지로 만드는 순서표 (Dockerfile)
🗺️ 그림 먼저 — 네 단계로 나눠 만들고, 마지막 것만 남긴다
① depsnpm ci (패키지 설치)
③ builder① + 코드 → next build
④ runner최종 이미지 (약 350MB)

② migrator 는 ① + 코드로 DB 마이그레이션만 하는 별도 이미지. ①~③ 은 만드는 데만 쓰고 최종 이미지에는 들어가지 않는다.

설치·빌드 도구는 실행할 때 필요 없습니다. 도구까지 담으면 이미지가 커지고(올리고 내려받기 느림), 공격받을 곳도 늘어나요.

먼저 Next.js 가 "실행에 필요한 파일만" 한 폴더에 모으게 합니다.

💡 왜 비밀값을 이미지에 넣지 않나요?이미지는 누구나 열어서 안의 파일을 볼 수 있습니다. .env.local 이 들어가면 이미지를 받은 사람이 DB 주소와 로그인 비밀키를 그대로 꺼내 갑니다. 비밀값은 실행할 때 환경 변수로 넣습니다. NEXT_PUBLIC_ 값만 예외 — 브라우저 코드에 빌드할 때 새겨지므로 빌드 인자로 넣고, 그래서 이 이름에는 공개돼도 되는 값만 씁니다.
🆘 작성자가 미리 막은 함정

우리 public 폴더는 비어 있어서 git 에 올라가지 않습니다. 그래서 GitHub 에서 받은 코드로 만들면 ④의 COPY /app/public 이 "폴더 없음"으로 실패해요 → Dockerfile 의 mkdir -p public 이 그 때문입니다.

🔁 방금 무슨 일이 일어났나"이 앱을 어떻게 상자에 담는지"를 순서표로 적었습니다. 이 순서표만 있으면 어느 컴퓨터에서든 똑같은 이미지가 나옵니다.
🤔 스스로 확인
패키지 목록(package.json)만 먼저 복사하고 npm ci 를 하는 이유는?

Docker 는 단계마다 결과를 저장해 둡니다(캐시). 코드만 바뀌고 패키지가 그대로면 npm ci 단계를 건너뛰어 다시 만들기가 빨라집니다.

HOSTNAME=0.0.0.0 이 없으면?

앱이 컨테이너 안에서만 요청을 받아서, 바깥(내 브라우저·Caddy)에서 접속할 수 없습니다.

3내 컴퓨터에서 띄워 보기 (docker compose)
🗺️ 그림 먼저 — 컨테이너 3개가 순서대로
dbPostgreSQL 18
migrate표 만들기 + 예시 데이터, 끝나면 멈춤

처음엔 Node·PostgreSQL 이미지를 내려받고 빌드하느라 몇 분 걸립니다. migrate 가 "Exited" 로 멈추는 건 정상이에요 — 할 일(표 만들기)을 끝낸 것입니다.

✅ 확인하는 법
  • http://localhost:3000 → 예시 프로젝트 목록 (화면 왼쪽 아래에 동그란 "N" 이 없으면 개발 서버가 아니라 운영용 빌드)
  • http://localhost:3000/api/health → {"ok":true,"db":"ok",...}
  • 다른 터미널에서 docker ps → app·db 가 (healthy)
  • 끄기: Ctrl+C → docker compose down (DB 까지 지우려면 down -v)
🆘 막혔을 때
개발 때와 똑같은 화면이 나와요 (예시 데이터)

정상입니다. compose 의 DB 는 컨테이너 안의 연습용 DB 라 예시 데이터가 들어갑니다. 운영 사이트와는 DB 가 달라요. 결제 버튼이 꺼져 있는 것도 정상 (토스 키를 넣지 않았으니까요).

Docker Desktop 창을 닫아도 되나요?

🆘 AMI 목록에서 헷갈리는 것

"HVM", "SSD Volume Type" 은 고르는 항목이 아니라 이름의 일부입니다. Ubuntu Pro(유료 지원), … with SQL Server(라이선스 요금 — 비쌈), Arm / t4g(우리 x86 이미지가 안 돎)는 고르지 않습니다. "프리 티어 사용 가능" = OS 추가 요금이 없다는 표시일 뿐, 서버 요금은 크레딧에서 빠집니다.

  2. 그 IP 를 체크 → 목록 위의 탄력적 IP 주소 연결 버튼 (작업 메뉴 안이 아닙니다) → 인스턴스 moa-ec2 → 연결

작업 메뉴의 "연결 해제"·"릴리스(=삭제)"는 누르지 않습니다. Name·역방향 DNS 가 비어 있는 건 정상.

✅ 확인하는 법인스턴스 실행 중 · 2/2 검사 통과, 퍼블릭 IPv4 = 탄력적 IP
🔁 방금 무슨 일이 일어났나서울에 작은 리눅스 컴퓨터를 빌리고, 주소가 바뀌지 않게 고정 IP 를 붙였습니다. 이 컴퓨터에는 열쇠 파일(.pem)을 가진 사람만 들어갈 수 있습니다.
🤔 스스로 확인
서버를 "중지"해 두면 요금이 0 일까?

아닙니다. 서버 요금은 멈추지만 고정 IP 와 디스크 요금은 계속 나갑니다. 그래서 실습이 끝나면 종료(삭제)하고 고정 IP 도 릴리스합니다.

🤔 스스로 확인
이미지 이름에 "커밋 SHA"를 붙이는 이유는?

어느 커밋으로 만든 이미지인지가 이름에 남아서, 되돌릴 때 "그 커밋의 이미지"를 정확히 고를 수 있습니다. latest 같은 이름은 가리키는 것이 바뀌어서 되돌리기 어렵습니다.

서버는 비공개 이미지를 어떻게 내려받나?

배포 작업이 자기 임시 열쇠(GITHUB_TOKEN, 작업이 끝나면 무효)를 SSH 로 건네주고, 서버는 그걸로 GHCR 에 잠깐 로그인했다가 로그아웃합니다. 서버에 오래 남는 토큰이 없습니다.
