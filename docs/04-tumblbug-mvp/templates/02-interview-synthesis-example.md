# 인터뷰 정리 예시

> ⚠️ **가상의 예시입니다.** 실제 인터뷰 결과가 아니라, "정리하면 이런 모양이 된다"를 보여주려고 만든 예시예요.
> 여러분의 인터뷰 결과는 이와 다를 수 있고, **달라야 정상**입니다. 이 예시를 그대로 PRD 근거로 쓰지 마세요.

## 인터뷰 대상 (가상)
| 코드 | 역할 | 배경 |
|---|---|---|
| 창작자 A | 창작자 | 일러스트 굿즈 제작, 펀딩 2회 |
| 창작자 B | 창작자 | 독립출판 준비 중, 펀딩 경험 없음 |
| 후원자 C | 후원자 | 1년에 3~4번 후원 |
| 후원자 D | 후원자 | 후원 1회, 친구 프로젝트 |
| 후원자 E | 후원자 | 망설이다 안 한 적이 많음 |

## 1. 인용 묶기
| 묶음 이름 | 인용 (가상) |
|---|---|
| 창작자는 진행 상황을 하루에도 여러 번 본다 | A: "아침에 눈 뜨자마자 얼마 모였는지부터 봤어요." |
| 목표 금액 정하기가 가장 어렵다 | A: "너무 높게 잡았다가 실패할까 봐 낮췄어요." / B: "얼마로 해야 할지 감이 안 와요." |
| 후원자는 '될 것 같은' 프로젝트에 후원한다 | C: "퍼센트가 좀 올라가 있으면 안심돼요." / E: "0%면 괜히 망설여져요." |
| 결제 단계에서 이탈한다 | E: "카드 입력하다가 귀찮아서 닫은 적 있어요." |
| 후원 후에도 다시 확인한다 | D: "친구 거라 성공했는지 계속 들어가 봤어요." |

## 2. 인사이트 → 설계에 주는 영향
| 인사이트 (한 문장) | 설계에 주는 영향 | PRD 반영 위치 |
|---|---|---|
| 창작자는 모금 중에 **현재 금액과 추세**를 자주 확인하고 싶어 한다 | 창작자 대시보드에 모인 금액·후원자 수·남은 일수를 첫 화면에 | 사용자 스토리 C-3 |
| 후원자는 **진행률이 어느 정도 있는** 프로젝트를 더 신뢰한다 | 목록 카드에 진행률 막대를 크게, 상세 상단에 % 강조 | 사용자 스토리 B-1 |
| 결제 과정이 길면 후원을 포기한다 | 후원 폼 입력칸 최소화(금액·메시지만), 퍼널로 이탈 측정 | 지표: 후원 시작 → 완료 |
| 후원자는 **후원한 프로젝트의 결과**가 궁금하다 | "내 후원 내역"에 프로젝트 상태(모금중/성공/실패) 표시 | 사용자 스토리 B-4 |
| 목표 금액 정하기가 어렵다 | (이번 범위 밖) 비슷한 프로젝트 참고 기능 → "다음에 할 것" 목록 | 비목표 / 향후 |

## 3. 가장 중요한 인사이트 1개 (케이스 스터디에 쓸 것)
> 후원 결정의 핵심 신호는 **진행률**이다. 그래서 진행률을 모든 화면에서 같은 모양(막대 + %)으로,
> 가장 먼저 보이게 한다.
