# 사용자 인터뷰 질문지 (1주차)

> 이 파일을 내 기획 폴더에 복사해서 쓰세요. `[ ]` 안은 내 상황에 맞게 바꿉니다.

## 인터뷰를 왜 하나요?
기능을 정하기 전에 **실제 사람이 지금 어떻게 하고 있고, 어디서 불편한지**를 듣기 위해서입니다.
"이런 기능 있으면 쓸 거예요?"라고 물으면 대부분 "네"라고 답합니다(예의상).
그래서 인터뷰는 **미래의 의견이 아니라 과거의 행동**을 묻습니다.

## 누구를, 몇 명
| 대상 | 인원 | 찾는 곳 (예) |
|---|---|---|
| 창작자 — 펀딩을 해봤거나 해보고 싶은 사람 | 2~3명 | 굿즈·책·공연을 만드는 지인, 동아리, 온라인 창작 커뮤니티 |
| 후원자 — 텀블벅·와디즈에서 후원해 본 사람 | 2~3명 | 친구, 가족, 동료 |

5명이면 큰 패턴의 대부분이 보입니다. 1명당 20~30분.

## 섭외 메시지 (예시)
```
안녕하세요! 크라우드펀딩 서비스를 공부하며 직접 만들고 있는 [이름]입니다.
[후원해 보신 / 펀딩을 준비해 보신] 경험을 20분 정도 여쭤보고 싶어요.
정답은 없고, 경험하신 그대로 말씀해 주시면 됩니다. 녹음은 허락해 주실 때만 할게요.
편하신 시간 알려주시면 맞출게요 🙏
```

## 진행 규칙
- **녹음은 동의를 받고**, 받지 못하면 메모만 합니다. 이름 대신 "창작자 A"처럼 기록합니다.
- 내 아이디어를 먼저 설명하지 않습니다. (듣는 사람이 거기에 맞춰 답하게 됨)
- "왜요?", "그때 어떻게 하셨어요?", "구체적으로 한 번 보여주실 수 있어요?"로 깊이 들어갑니다.
- 유도 질문 금지: ❌ "후원할 때 진행률이 중요하죠?" → ⭕ "후원할지 말지 정할 때 뭘 보셨어요?"
- 침묵을 두려워하지 않습니다. 3초 기다리면 더 많은 이야기가 나옵니다.

## 질문 — 창작자용
1. 최근에 만든(만들고 싶은) 것은 무엇인가요? 어떻게 알리고 팔았나요?
2. 크라우드펀딩을 해보셨다면: 준비부터 끝까지 순서대로 이야기해 주세요. 가장 오래 걸린 일은?
3. 목표 금액과 마감일은 어떻게 정했나요? 그때 가장 걱정한 것은?
4. 펀딩 중에 매일 확인한 것이 있다면? (얼마나 모였는지, 누가 후원했는지 …)
5. 가장 답답했던 순간은? 그때 어떻게 해결했나요?
6. (안 해봤다면) 해보지 않은 이유는 무엇인가요?

## 질문 — 후원자용
1. 가장 최근에 후원한 프로젝트는? 처음 어떻게 알게 되었나요?
2. 후원할지 말지 정할 때 무엇을 봤나요? 망설이다가 그만둔 적이 있나요? 왜?
3. 결제하는 과정에서 기억나는 것이 있나요? (불편했던 점, 좋았던 점)
4. 후원한 뒤에 다시 들어가서 확인한 적이 있나요? 무엇을 확인했나요?
5. 목표를 못 채운 프로젝트를 후원해 본 적이 있나요? 그때 기분은?

## 마무리 (공통)
- "오늘 이야기 중에 제가 꼭 기억해야 할 것 하나만 꼽는다면요?"
- "비슷한 경험을 가진 분을 소개해 주실 수 있을까요?"

## 기록 양식 (인터뷰 1명당 1장)
```
## 인터뷰: [창작자 A] · [날짜] · [시간]분
- 배경: (무엇을 만드는/후원하는 사람인지 한 줄)
- 인상 깊은 말 (그대로 인용):
  - "..."
  - "..."
- 관찰한 행동/순서:
- 불편·걱정:
- 이미 쓰고 있는 해결 방법(우회로):
- 내 생각 (인용과 구분해서):
```

## 정리하는 법 (인터뷰가 끝나면)
1. 모든 인용을 포스트잇(또는 한 줄씩)으로 옮긴다
2. 비슷한 것끼리 묶는다 → 묶음마다 이름을 붙인다 (예: "진행 상황을 자주 확인한다")
3. 묶음마다 **인사이트**를 한 문장으로: "[누가]는 [상황]에서 [무엇]을 원한다, 왜냐하면 [이유]"
4. 인사이트 → 기능/설계에 어떤 영향을 주는지 적는다 → PRD에 반영

예시는 `02-interview-synthesis-example.md`를 보세요.
