도구를 준비하고, 첫 웹페이지 만들기

이번 주 마지막에는 내 컴퓨터에서 열리는 자기소개 페이지가 생깁니다. 아직 인터넷에 올리지는 않아요(2주차에 합니다).

1개발 도구 3개 설치하기
도구하는 일설치
VSCode코드를 쓰는 메모장 (코드 편집기)code.visualstudio.com → 설치 중 "PATH에 추가"와 "Code(으)로 열기" 항목을 모두 체크
Git코드의 저장 기록을 관리. 설치하면 Git Bash(터미널)도 함께 생김git-scm.com → 설치 화면은 모두 기본값으로 Next
Node.js브라우저 밖에서 JavaScript를 실행하는 프로그램nodejs.org → LTS 버전

설치가 끝나면 VSCode를 열고 Ctrl + `(숫자 1 왼쪽 키)로 아래쪽에 터미널을 엽니다. 터미널 오른쪽 위 ∨ 버튼을 눌러 Git Bash를 고르세요. 이 교재의 모든 명령어는 Git Bash 기준입니다.

Git에 내 이름과 이메일을 등록합니다. 나중에 GitHub 가입에 쓸 이메일을 넣으세요.

✅ 확인하는 법node -v는 v22.x.x처럼(20.9 이상), git --version은 git version 2.x처럼 숫자가 나오면 성공입니다.
🆘 막혔을 때
command not found가 나와요

설치 직후에는 VSCode를 완전히 껐다가 다시 켜야 새 프로그램을 인식합니다. 그래도 안 되면 컴퓨터를 재시작하세요.

터미널 목록에 Git Bash가 없어요

Git을 설치한 뒤 VSCode를 다시 켜세요. 그래도 없으면 Ctrl+Shift+P → "Terminal: Select Default Profile" → Git Bash 선택.

2웹은 어떻게 동작하나

시작 페이지의 흐름도를 다시 보고 오세요. 핵심은 딱 세 가지입니다.

📖 용어 풀이
  • 클라이언트 / 서버: 식당으로 치면 손님(클라이언트 = 브라우저)과 주방(서버). 손님이 주문(요청)하면 주방이 음식(응답)을 내줍니다.
  • URL(주소): 어느 주방에 무엇을 주문할지 적은 것. 예: https://youtube.com/@channel → https://(안전한 통신 방식) + youtube.com(어느 서버) + /@channel(그 서버의 어느 페이지)
  • HTML · CSS · JavaScript: 서버가 보내주는 세 종류의 파일. 사람 몸에 비유하면 뼈대 · 옷 · 행동입니다.
  • 데이터베이스: 주방의 창고. 회원 정보처럼 오래 보관해야 하는 데이터를 둡니다. 1단계에서 처음 씁니다.
💡 직접 확인해보기아무 사이트에서 F12를 누르면 개발자 도구가 열립니다. Network 탭을 연 채로 새로고침(F5)하면, 브라우저가 서버에 보낸 요청과 받은 파일(html, css, js …)이 줄줄이 보입니다. 그림 속 ②③이 실제로 일어나는 모습이에요.
3터미널 기본 명령어

터미널은 마우스 대신 글자로 컴퓨터에 명령하는 창입니다. 개발 도구 대부분이 터미널 명령어로 동작해서 피할 수 없어요. 대신 자주 쓰는 건 몇 개 안 됩니다.

명령어뜻예시
pwd지금 내가 있는 폴더 위치 보기pwd
ls지금 폴더 안의 파일 목록 보기ls
cd 폴더폴더로 들어가기cd dev
cd ..한 단계 위 폴더로 나가기cd ..
cd ~내 홈 폴더로 가기 (~ = 홈)cd ~
mkdir -p 폴더폴더 만들기 (-p: 중간 폴더도 같이)mkdir -p ~/dev
code .지금 폴더를 VSCode로 열기 (. = 지금 폴더)code .
clear터미널 화면 지우기clear

키보드 요령: Tab = 파일/폴더 이름 자동 완성, ↑ = 이전 명령어 다시 불러오기, Ctrl+C = 실행 중인 프로그램 멈추기

이번 과정의 작업 폴더를 만들고, 자기소개 페이지 폴더로 들어가 VSCode로 엽니다.

✅ 확인하는 법pwd 결과가 /c/Users/내이름/dev/about-me처럼 나오고, 새 VSCode 창이 ABOUT-ME라는 빈 폴더로 열리면 성공입니다. 앞으로는 이 새 창에서 작업합니다.
🆘 막혔을 때
code: command not found

VSCode 설치 때 "PATH에 추가"를 체크하지 않았습니다. VSCode에서 Ctrl+Shift+P → "Shell Command: Install 'code' command in PATH"를 실행하거나, VSCode 메뉴 File → Open Folder로 about-me 폴더를 직접 여세요.

4HTML: 페이지의 뼈대 만들기

HTML은 태그로 내용에 이름표를 붙이는 언어입니다. <h1>제목</h1>처럼 여는 태그와 닫는 태그(/가 붙음) 사이에 내용을 넣습니다. 태그 안에 추가 정보를 적는 것을 속성이라고 해요: <a href="주소">

VSCode 왼쪽 파일 목록에서 새 파일 버튼을 눌러 index.html을 만들고 아래 코드를 붙여넣은 뒤 저장(Ctrl+S)합니다. 이름, 소개, 링크는 내 것으로 바꾸세요.

태그뜻
<head>화면에 안 보이는 정보 (글자 인코딩, 탭 제목 등)
<meta charset="utf-8">한글이 깨지지 않게 하는 설정 — 꼭 필요
<body>화면에 보이는 내용 전체
<h1>, <h2>제목 (숫자가 작을수록 큰 제목)
<p>문단
<ul> + <li>목록과 목록의 한 항목
<a href="…">링크. target="_blank"는 새 탭에서 열기

파일 탐색기에서 index.html을 더블클릭하거나, 터미널에서 아래 명령어로 브라우저에서 엽니다.

✅ 확인하는 법흰 배경에 큰 제목, 목록 2개, 파란 밑줄 링크 3개가 보이면 성공입니다. 아직 꾸미지 않아서 투박한 게 정상이에요. 코드를 고친 뒤에는 저장하고 브라우저에서 새로고침(F5)해야 반영됩니다.
🆘 막혔을 때
한글이 이상한 문자로 깨져 보여요

<meta charset="utf-8"> 줄이 빠졌거나, VSCode 오른쪽 아래 인코딩 표시가 UTF-8이 아닌 경우입니다.

더블클릭하면 브라우저가 아니라 메모장으로 열려요

파일 이름이 index.html.txt일 수 있습니다. VSCode 파일 목록에서 이름을 확인하세요.

폼(form) 맛보기 — 1단계 로그인 화면의 재료

1단계에서 회원가입·로그인 화면을 만들 때 쓰는 태그들입니다. 같은 폴더에 form.html을 만들어 열어보세요.

✅ 확인하는 법
  • 아무것도 안 쓰고 "가입하기" → "이 입력란을 작성하세요." 같은 말풍선이 뜬다
  • 이메일에 abc만 쓰고 제출 → "@를 포함해 주세요" 같은 안내가 뜬다
  • 비밀번호는 입력하면 ●●●로 가려진다
💡 이 검사만 믿으면 안 돼요이 말풍선은 브라우저가 해주는 편의 기능입니다. F12로 required를 지워버리면 누구나 통과할 수 있어요. 그래서 1단계 3주차에서는 같은 검사를 서버에서 한 번 더 합니다. 지금은 "화면의 검사는 우회할 수 있다"만 기억해 두세요.

5CSS: 페이지에 옷 입히기

CSS는 "어떤 요소를 어떻게 꾸밀지"를 적는 언어입니다. 형식은 항상 같아요.

📖 용어 풀이
  • 선택자: 꾸밀 대상. body(태그 이름), .links(점 + class 이름), .links a(links 안에 있는 a 태그)
  • class: HTML 요소에 붙이는 별명. <ul class="links">처럼 붙이면 CSS에서 .links로 부를 수 있습니다.
  • CSS 변수: --bg: #f7f7f8;처럼 값에 이름을 붙여 두고 var(--bg)로 꺼내 씁니다. 색을 바꿀 때 한 곳만 고치면 됩니다.
  • flex: 요소들을 가로 또는 세로로 가지런히 늘어놓는 배치 방법. gap으로 간격을 줍니다.

같은 폴더에 style.css를 만듭니다.

index.html에 세 군데를 고칩니다: ① <head> 안에 CSS 파일 연결(<link rel="stylesheet">) ② 소개 문단에 class="muted" ③ 링크 목록에 class="links"

✅ 확인하는 법새로고침하면 내용이 가운데로 모이고, 링크가 둥근 버튼 모양으로 바뀝니다. 벌써 Linktree처럼 보이죠? 버튼에 마우스를 올리면 테두리가 파랗게 됩니다.
💡 실험해보기F12 → Elements 탭에서 요소를 클릭하면 오른쪽 Styles에 적용된 CSS가 보입니다. 값을 직접 바꿔보면 화면이 즉시 바뀝니다(새로고침하면 원래대로). --primary 색을 바꿔보거나 border-radius를 0으로 바꿔보세요.
🆘 막혔을 때
CSS가 전혀 적용되지 않아요

style.css가 index.html과 같은 폴더에 있는지, <link rel="stylesheet" href="style.css">의 파일 이름 철자가 맞는지 확인하세요.

일부만 적용돼요

CSS에서 중괄호 { }나 세미콜론 ;이 빠지면 그 뒤가 무시됩니다. VSCode에서 빨간 물결 밑줄이 있는지 보세요.
