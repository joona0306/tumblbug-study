JavaScript로 움직이게 하고, 인터넷에 올리기

이번 주에는 1단계 코드에 계속 나오는 JavaScript 문법을 익히고, 자기소개 페이지를 실제 인터넷 주소로 공개합니다.

1JavaScript 핵심 문법 (터미널에서 실행)

화면 없이 문법만 연습하려고 Node.js로 실행합니다. 새 폴더를 만들어 VSCode로 여세요.

먼저 다른 파일에서 가져다 쓸 함수를 담은 utils.mjs를 만듭니다.

그리고 연습 파일 practice.mjs를 만듭니다. 번호마다 주석(// 뒤의 설명)을 먼저 읽어보세요.

✅ 확인하는 법

아래처럼 1~7이 순서대로 나오면 성공입니다. 6번 두 줄 사이에 0.5초 멈추는 것도 눈여겨보세요 — await가 기다린 시간입니다.

이 7가지는 모두 1단계 코드에 그대로 나옵니다.

문법1단계에서 이렇게 쓰여요

템플릿 문자열 `${ }`공개 페이지 주소 만들기 `/${user.username}`

async / awaitDB에 물어보고 답을 기다리기 await db.select()…

2브라우저의 JavaScript: 버튼이 동작하게 만들기

자기소개 페이지(~/dev/about-me)로 돌아갑니다. 시간대별 인사말과 다크 모드 버튼을 붙여볼게요.

📖 용어 풀이
  • DOM: 브라우저가 HTML을 읽어서 만든 "조작 가능한 요소 나무". JavaScript는 DOM을 통해 화면을 바꿉니다. document.querySelector("#greeting") = "id가 greeting인 요소 찾아줘"
  • 이벤트: 클릭, 입력 같은 사용자 행동. addEventListener("click", 함수) = "클릭되면 이 함수 실행해줘"

같은 폴더에 script.js를 만듭니다.

index.html에 ① <script> 연결, ② 인사말 자리(id="greeting"), ③ 버튼(id="theme-button")을 추가합니다.

style.css에 다크 모드 색과 버튼 모양을 추가합니다. body.dark { … } 블록(맨 위 :root 바로 아래)과 맨 끝의 button { … } 블록이 새로 생겼어요.

💡 변수로 색을 정해둔 덕분다크 모드에서 바뀌는 건 변수 값 6개뿐입니다. 1주차에 색을 var(--bg)처럼 변수로 써둔 덕분에, 요소마다 색을 다시 지정할 필요가 없어요. 1단계 교재 코드도 같은 방식입니다.
📖 defer는 뭔가요?<script src="script.js" defer>의 defer는 "HTML을 다 읽은 다음에 실행해"라는 뜻입니다. 없으면 버튼이 아직 만들어지기 전에 스크립트가 버튼을 찾으려다 실패합니다.
✅ 확인하는 법
  • 새로고침하면 맨 위에 지금 시각에 맞는 인사말(아침/오후/저녁)이 보인다
  • "🌙 다크 모드로" 클릭 → 배경이 어두워지고 버튼 글자가 "☀️ 라이트 모드로"로 바뀐다. 다시 누르면 원래대로
🆘 막혔을 때
버튼을 눌러도 아무 일도 안 일어나요

F12 → Console 탭에 빨간 에러가 있는지 보세요. Cannot read properties of null이면 HTML의 id와 script.js의 "#theme-button" 철자가 다른 경우가 대부분입니다.

3JSX 읽는 법 (1단계 미리보기)

1단계에서 쓰는 Next.js(React)는 화면을 JSX로 만듭니다. JSX는 "JavaScript 안에 쓰는 HTML"이에요. 아래는 1단계에서 실제로 만들 공개 페이지 코드의 일부입니다. 내 자기소개 페이지의 링크 목록과 비교해 보세요.

HTML (0단계)JSX (1단계)뜻
class="links"className="public-links"JavaScript에서 class는 다른 뜻의 예약어라 이름만 바뀜
링크를 손으로 3줄 씀{links.map((item) => ( … ))}DB에서 가져온 링크 개수만큼 자동으로 반복 (1단계 map)
<a href="https://…"><a href={item.url}>{ } 안에는 JavaScript 값을 넣을 수 있음
(없음){조건 ? (A) : (B)}조건이 참이면 A, 아니면 B를 보여줌 (링크가 0개면 안내 문구)
(없음)key={item.id}반복되는 항목마다 붙이는 고유 번호. React가 어느 항목이 바뀌었는지 알아보는 데 씀
💡 지금은 "읽을 수 있으면" 충분합니다이 코드를 외우거나 따라 칠 필요는 없어요. 1단계에서 이 모양을 처음 봤을 때 "아, 이건 목록을 반복하는 거구나" 정도로 읽히면 성공입니다.
4Git으로 저장 기록 남기기

Git은 코드의 "저장 기록"을 남기는 도구입니다. 게임의 세이브 포인트처럼, 언제든 예전 상태로 돌아가거나 무엇이 바뀌었는지 볼 수 있어요.

about-me 폴더에서 저장소를 만들고 첫 커밋을 합니다.

명령어뜻
git init이 폴더를 Git 저장소로 만들기 (처음 한 번만)
git status지금 무엇이 바뀌었는지 보기 — 헷갈리면 언제든 치세요
git add .바뀐 파일 전부를 저장 대기로 (. = 전부)
git commit -m "메모"저장! 메모에는 "무엇을 했는지"를 짧게
git log --oneline저장 기록 목록 보기
📖 .gitignore 미리보기Git에 올리면 안 되는 파일(비밀번호가 든 설정 파일 등)은 .gitignore라는 파일에 적어 제외합니다. 지금은 필요 없지만, 1단계에서 DB 비밀번호를 담은 .env.local을 이 방법으로 숨깁니다.
✅ 확인하는 법git log --oneline에 자기소개 페이지 완성이 한 줄 보이고, git status가 nothing to commit, working tree clean이라고 하면 성공입니다.
🆘 막혔을 때
Please tell me who you are

1주차 1단계의 git config --global user.name / user.email을 안 했습니다. 실행 후 다시 커밋하세요.

  2. github.com/new에서 새 저장소: 이름 about-me, Public, README 등 추가 옵션은 모두 체크하지 않음 → Create repository

6Vercel로 첫 배포 + 1단계 준비

이제 인터넷 주소를 붙입니다. Vercel은 GitHub 저장소를 연결하기만 하면 자동으로 사이트를 열어주는 서비스입니다.

  1. vercel.com → Continue with GitHub로 가입, 플랜은 Hobby(무료)
  2. vercel.com/new → about-me 옆 Import
  3. Framework Preset은 Other 그대로 (빌드가 필요 없는 순수 HTML이라서) → Deploy
  4. 잠시 뒤 축하 화면과 함께 https://about-me-….vercel.app 주소가 생깁니다
📖 용어 풀이배포: 내 컴퓨터에만 있던 파일을 24시간 켜진 서버에 올려 누구나 주소로 접속하게 만드는 것. 시작 페이지 흐름도의 "서버" 역할을 Vercel이 해줍니다.
✅ 확인하는 법
  • 휴대폰(와이파이 끄고 데이터로)에서 내 주소가 열린다 — 이제 전 세계 누구나 볼 수 있습니다 🎉
  • 자동 배포 확인: index.html의 소개 문장을 조금 고친 뒤 아래 명령어 → 1~2분 뒤 새로고침하면 인터넷 페이지에도 반영된다
