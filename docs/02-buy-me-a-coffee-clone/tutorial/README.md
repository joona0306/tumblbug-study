# 2단계 HTML 교재 — Buy Me a Coffee 클론

`index.html`을 더블클릭해서 브라우저로 열면 됩니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 시작 페이지: 완성본 미리보기, 새로 배우는 것, 결제 흐름도(브라우저·내 서버·토스), 준비물 |
| `week1.html` | 1주차: 경쟁 분석, 범위·성공 지표, 와이어프레임 + 후원 상태 변화도, 디자인 재사용, 1단계 코드 가져오기, 소개(bio) 칸 추가 마이그레이션 |
| `week2.html` | 2주차: support 표, 키 위치 그림, 결제 요청 + 결제위젯, 서버 승인(금액 위조 차단), 실패·취소 처리 |
| `week3.html` | 3주차: 후원 내역·메시지, 크리에이터 대시보드, 내 서비스 공격해보기 |
| `week4.html` | 4주차: 배포(환경 변수 5개), 테스트 결제 10회 시나리오, 결제 완료율·실패 추적 SQL, 사용성·접근성, 개선, 부록 "실제로 돈을 받으려면" |

## 작성자용: 코드 블록 동기화
```bash
node tools/sync-tutorial-code.mjs docs/02-buy-me-a-coffee-clone/tutorial projects/02-buy-me-a-coffee-clone
```
