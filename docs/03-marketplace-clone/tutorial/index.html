시작하기 전

💡 왜 3단계에서 TypeScript를 시작하나요?1·2단계는 개념에 집중하려고 JavaScript로 썼습니다. 3단계부터는 파일과 조건이 많아져서 "이 값이 문자열인가 숫자인가?", "이 칸은 없을 수도 있나?" 같은 실수가 늘어납니다. TypeScript는 이런 실수를 코드를 실행하기 전에 빨간 줄로 알려줍니다. 1주차에 1단계 코드를 직접 바꿔 보면서, 타입이 실제로 무엇을 잡아주는지 경험합니다.

이 단계를 끝냈다는 기준

  • 사진을 포함해 상품을 등록하고, 목록에서 검색·필터로 찾을 수 있다
  • 판매 상태를 바꾸면 목록과 상세에 바로 반영된다
  • 내 상품만 수정·삭제할 수 있다 (서버에서 검사)
  • 판매자 연락 방법은 로그인한 사람에게만 보인다
  • 상품을 삭제하거나 사진을 바꾸면 저장소의 옛 사진도 지워진다
  • 키보드로 등록·검색할 수 있고, 사진에 대체 텍스트가 있고, Lighthouse 접근성 90점 이상
