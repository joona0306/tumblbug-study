# 3단계 HTML 교재 — 당근마켓 미니 클론 (TypeScript)

`index.html`을 더블클릭해서 브라우저로 열면 됩니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 시작 페이지: 완성본 미리보기, 새로 배우는 것, 사진 업로드 흐름도, 완료 기준 |
| `week1.html` | 1주차: 경쟁 분석·범위·지표, user–product 관계도, 카드 디자인, 1단계 코드 가져오기, **JavaScript → TypeScript 전환**(실제 에러와 해결), 연락 방법 칸 |
| `week2.html` | 2주차: 상품 표(enum·$inferSelect·타입 가드), Vercel Blob 사진 업로드(브라우저에서 줄이기), 목록, 수정·삭제와 옛 사진 정리 |
| `week3.html` | 3주차: 검색 흐름도, 제목 검색(이스케이프), 카테고리·판매중 필터(주소에 상태), 판매 상태 변경(Object.hasOwn 함정), 연락 방법 권한, 내 판매 상품 |
| `week4.html` | 4주차: 운영용 DB·사진 저장소 분리, 배포, 거래완료율, 고아 사진 점검, 사용성·접근성(대비 문제 실제 사례), 개선, 4단계 준비 |
