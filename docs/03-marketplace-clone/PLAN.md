# 3단계: 당근마켓 미니 클론 — 교재 기획서

**교재 제작 상태**: 기획 확정 / 정답 코드 작성 중
**학습 기간**: 1개월 (1~4주차)
**학습 목표**: 1:N 데이터 관계, 검색/필터(주소에 상태 담기), 상태값(판매중/거래완료),
파일(이미지) 업로드, "로그인한 사람에게만 보여주기" 권한 다루는 법 익히기

## 선수 지식
- 1~2단계 완료 (특히 1단계 코드를 복사해 새 서비스를 시작하는 법)
- 계정: Vercel (이미지 저장소 Vercel Blob을 같은 계정에서 만든다)

## 문제 정의
> 동네 중고거래처럼, 사용자가 상품을 올리고 다른 사용자가 검색/필터로 찾아
> 연락 방법을 확인할 수 있게 한다. (채팅 기능은 제외 — 연락 방법만 공개)

## 기능 범위

| 포함 | 제외 |
|---|---|
| 상품 등록/수정/삭제 (사진 1장, 제목·가격·카테고리·설명) | 채팅 기능, 사진 여러 장 |
| 상품 목록 + 제목 검색 | 위치 기반(동네 인증), 정렬 옵션 |
| 카테고리 필터, 판매중만 보기 | 알림(찜하기 알림 등), 찜하기 |
| 판매 상태 변경 (판매중 ↔ 거래완료) | 신고/차단, 거래 후기 |
| 판매자 연락 방법 (로그인한 사람에게만 공개) | 결제·안전거래 |
| 내 판매 상품 목록 + 연락 방법 수정 | 페이지 나누기(최신 60개까지만) |

## 화면 목록
1. 상품 목록 `/` — 검색창 + 카테고리 + 판매중만 보기 (조건은 주소 `?q=&category=&onSale=` 에 담김)
2. 상품 상세 `/products/[id]` — 사진, 가격, 설명, 판매자, 연락 방법(로그인 시), 본인이면 수정·삭제·상태 변경
3. 상품 등록 `/products/new`, 수정 `/products/[id]/edit` (본인만)
4. 내 판매 상품 `/dashboard` — 내 상품 목록, 연락 방법 수정
5. 회원가입 / 로그인 (1단계 재사용)

## 데이터 구조
```
user    : 1단계 Better Auth 구조 재사용 + contact(연락 방법: 오픈채팅 링크 등)
product : id, user_id, title, price, category, description, status(selling/sold),
          image_url, created_at, updated_at
```
- 관계: `user` 1 : N `product`
- 카테고리는 정해진 목록(디지털기기, 가구/인테리어, 의류, 도서, 생활가전, 기타) 중 하나

## 결정 사항
- **이미지 저장소: Vercel Blob** — 같은 Vercel 계정에서 만들고 토큰 하나(`BLOB_READ_WRITE_TOKEN`)로 연결.
  카드 등록 없이 시작할 수 있어 초심자에게 가장 간단. (Cloudflare R2는 무료 용량이 크지만 가입 절차가 더 복잡)
- **사진 크기**: 휴대폰 사진은 수 MB라 서버로 보내기 전에 **브라우저에서 줄인다**(가로 최대 1280px, JPEG).
  서버 액션 요청 크기 제한을 넘지 않게 하고, 저장 용량·로딩 속도도 아끼기 위해
- **검색**: 제목에 검색어가 들어간 상품 (대소문자 무시, `%`·`_` 같은 특수문자는 글자 그대로 취급)

## 성공 지표
- **등록된 상품 중 거래완료로 바뀐 비율** — 사고파는 연결이 실제로 일어났는지를 보여줌

## 주차별 체크리스트
- [ ] 1주차: 경쟁 서비스 분석 / 범위·성공 지표 / 와이어프레임 + user–product 1:N 관계도 / 디자인(카드 목록) /
  1단계 코드 가져와 시작 + 연락 방법 칸
- [ ] 2주차: product 표 / 사진 업로드(Vercel Blob, 브라우저에서 줄이기) + 등록 / 목록 / 상세 / 수정·삭제(본인만, 사진 교체·삭제)
- [ ] 3주차: 검색 / 카테고리·판매중 필터(주소에 상태 담기) / 판매 상태 변경 / 연락 방법 공개 권한 / 내 판매 상품
- [ ] 4주차: 배포 / 지표 측정 / 운영 루프(저장소 용량·고아 이미지 점검) / 사용성·접근성(사진 대체 텍스트) / 개선 / 회고 / 4단계 준비

## 운영 루프 (4주차)
- 1단계에서 배운 사용량 측정(Vercel Analytics + SQL 지표)으로 거래완료율, 카테고리별 등록 수 확인
- Vercel Blob 저장 용량 확인, DB에 없는데 저장소에 남은 사진(고아 이미지) 점검
- 지표 확인 → 사용성 테스트 → 가설 → 개선 1개 → 재측정

## 완료 기준 (Definition of Done)
- [ ] 상품 등록(사진 포함) 후 목록에서 검색/필터로 정상 조회됨
- [ ] 판매 상태를 변경하면 목록/상세 화면에 즉시 반영됨
- [ ] 본인 상품만 수정/삭제 가능하고 타인 상품은 불가능함 (서버에서 권한 검사)
- [ ] 판매자 연락 방법은 로그인한 사람에게만 보임
- [ ] 상품을 삭제하거나 사진을 바꾸면 저장소의 옛 사진도 지워짐
- [ ] 키보드로 등록·검색 가능, 사진에 대체 텍스트, Lighthouse 접근성 90점 이상
